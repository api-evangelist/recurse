# Product: Recurse ML | AI Code Review Tool for Developers and AI Agents
# Intent: Introduce Recurse ML as an AI-powered code review agent that catches bugs in human and AI-generated code, cuts review time by 80%, and prevents production bugs through intelligent analysis.
Description: Recurse ML is the AI code review platform built specifically for modern development workflows that integrate AI coding assistants like Cursor, Claude Code, and GitHub Copilot. Unlike traditional code review tools, Recurse understands your entire codebase context, detects subtle bugs that tests and static analyzers miss, and provides actionable feedback with one-click fixes. Recurse serves as a self-healing feedback loop for AI agents, automatically catching and correcting mistakes before code reaches production. With deep codebase understanding, Recurse identifies breaking changes, library misuse, SQL query issues, and logic bugs across your entire application. Trusted by development teams worldwide, and with a zero data retention policy for your code, Recurse helps organizations ship reliable code faster while maintaining the highest security and quality standards.
